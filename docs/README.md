# Struq Voice documentation

Start with [`AGENTS.md`](../AGENTS.md) in the repo root. It routes a task to
the skill that owns it, and most work needs one skill plus that file rather
than anything here.

Read a document from this folder when the table says you need it.

## Reference: these bind behavior

| Document | Owns | Read it when |
|---|---|---|
| [`ARCHITECTURE.md`](ARCHITECTURE.md) | The process and window model, and the boundaries between them | Adding a window, moving work between processes, or wondering why the renderer cannot import from main |
| [`DESIGN_SYSTEM.md`](DESIGN_SYSTEM.md) | Evergreen and Ember: color, type, spacing, motion, and what never ships | Any UI work. A view that fights this document is a bug |
| [`FEATURES.md`](FEATURES.md) | What is built, what is partial, what is a known gap | Before claiming something exists, and after shipping a user-visible capability |
| [`MODELS.md`](MODELS.md) | Engines, the model catalog, the download and verification pipeline | Touching transcription, adding a model, or debugging a download |
| [`RELEASING.md`](RELEASING.md) | Cut, sign, verify, publish, the manual pre-release checklist, and why updates are signed | Shipping a version, or when an update does not arrive |
| [`TESTING.md`](TESTING.md) | The risk-weighted test strategy and what each layer is for | Deciding whether something needs a test, and which kind |
| [`TROUBLESHOOTING.md`](TROUBLESHOOTING.md) | Known failures and their fixes | A native module will not load, or something broke in a way that feels familiar |

## Conventions

- **A plan is disposable; the record is not.** Plans live in `docs/plans/`
  while the work is in flight. When it lands, promote anything durable (a
  decision, a trap worth remembering) into the reference documents above and
  delete the plan. Before deleting, grep for its filename: a doc or comment
  pointing at a deleted file is a dangling reference.
- **Docs move in the same commit as the behavior they describe.** Not a
  follow-up. The mapping from change to document is in the `github-workflow`
  skill.
- **If a command can answer it, a document does not get to assert it.** What
  landed is `git log`. What is installed is `package.json`. A file that
  restates those goes stale.
- **No em dashes, en dashes or horizontal bars.** Commas, colons,
  parentheses, or two sentences.
